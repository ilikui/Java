# 面向对象：类、封装、继承与多态

## 核心概念

- **类**：描述状态与行为的类型定义。
- **对象**：类的运行时实例。
- **封装**：控制状态的访问，通过方法维护不变量。
- **继承**：建立 is-a 关系并复用/扩展行为，应避免为了复用而滥用。
- **多态**：通过共同父类型调用不同实现。
- **接口**：定义调用方依赖的行为契约。
- **抽象类**：在相关类型之间共享状态或部分实现。

## 示例：面向接口编程

```java
interface Notifier {
    void send(String message);
}

final class ConsoleNotifier implements Notifier {
    @Override
    public void send(String message) {
        System.out.println(message);
    }
}

class AlertService {
    private final Notifier notifier;

    AlertService(Notifier notifier) {
        this.notifier = notifier;
    }

    void alert(String message) {
        notifier.send(message);
    }
}
```

`AlertService` 依赖 `Notifier` 抽象，而不是绑定某个具体发送方式，因此可以替换实现，也更容易测试。

## 设计时要问的问题

1. 对象的状态是否可能进入非法状态？
2. 字段是否应该由调用方直接修改？
3. 这里是真正的 is-a 关系，还是更适合组合？
4. 接口是否表达稳定的业务能力？
5. 一个类是否承担了过多变化原因？

## 常见误区

- 所有字段一律 public，导致对象无法保护自身状态。
- 为了复用代码而构造不合理的继承层级。
- 忘记 `@Override`，导致方法签名不匹配。
- 混淆重载（编译期根据参数选择）与重写（运行期动态分派）。
- 认为构造器会被继承；构造器不会像普通实例方法那样被继承。
