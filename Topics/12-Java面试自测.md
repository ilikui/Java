# Java 面试自测清单

> 先独立作答，再回到对应专题补齐证据。回答时尽量包含定义、机制、适用场景、限制和一个实际例子。

## 语言基础

- [ ] Java 是值传递还是引用传递？举例说明。
- [ ] `==` 与 `equals` 的区别是什么？
- [ ] String 为什么常被称为不可变对象？不可变的价值是什么？
- [ ] 重载、重写与动态分派分别是什么？
- [ ] 接口与抽象类如何选择？

## 集合与泛型

- [ ] ArrayList 的扩容与插入成本如何理解？
- [ ] HashMap 如何利用 hashCode 和 equals 处理键？
- [ ] 为什么 equals 与 hashCode 必须遵守契约？
- [ ] 泛型擦除意味着什么？有哪些限制？
- [ ] ConcurrentHashMap 与 HashMap 的使用边界是什么？

## 异常与工程化

- [ ] checked 与 unchecked exception 有什么区别？
- [ ] try-with-resources 如何管理资源？
- [ ] Maven 生命周期、插件和依赖是什么关系？
- [ ] 单元测试、集成测试、端到端测试有什么区别？

## JVM

- [ ] 堆、虚拟机栈、程序计数器与 Metaspace 的区别是什么？
- [ ] 类加载的主要阶段是什么？
- [ ] 如何区分内存泄漏与正常缓存增长？
- [ ] 发生高 CPU、频繁 GC 或 OOM 时，你会先收集什么证据？

## 并发

- [ ] volatile 能保证什么，不能保证什么？
- [ ] 什么是竞态条件、死锁和可见性问题？
- [ ] 线程池参数如何结合业务选择？
- [ ] Future 超时后任务是否一定停止？
- [ ] 如何安全关闭线程池？

## 数据库与后端

- [ ] PreparedStatement 如何降低 SQL 注入风险？
- [ ] 索引的收益和成本是什么？
- [ ] 事务的 ACID 是什么？
- [ ] REST API 如何设计校验、错误响应与分页？
- [ ] 如何划分 Controller、Service 与数据访问层？

## 项目表达模板

讲项目时按以下顺序组织：

1. 背景与要解决的问题。
2. 需求范围和关键约束。
3. 架构与技术选型，说明为什么这样选。
4. 自己负责的核心实现。
5. 遇到的故障、定位过程和修复证据。
6. 测试方式、结果与尚存限制。
7. 如果重做，会优先改进什么。

## 自我评分

- 0 分：没有概念。
- 1 分：能背出定义。
- 2 分：能解释机制并给出示例。
- 3 分：能讨论边界、代价、故障定位与替代方案。

每次复盘优先补齐 0–1 分的知识点。
